# M1: working-paper replication audit

**Status: implemented, not reproduced.** The primary experiment does not satisfy the M1 numerical acceptance criteria. No M2 work has begun.

## Scope and provenance

The supplied reference is the October 5, 2006 working paper by Avellaneda and Stoikov. The uploaded JSON matches Tables 1-3 on PDF pages 11-12. It is preserved byte-for-byte, including its `verified_by_human: false` flag. The published 2008 article was not supplied or verified.

The complete experiment ran from clean source commit `2b75c0be72bab5ec2fc9e0c841fd1ce9af8feb86`. Inputs, child random streams, output hashes and environment versions are in [manifest.json](../evidence/m1/run/manifest.json). All case outcomes are in [comparison.json](../evidence/m1/run/comparison.json). Terminal path samples accompany those files as Parquet. The supplied PDF checksum is recorded in [source_audit.json](../evidence/m1/source_audit.json).

## Method

Each strategy/case uses 1,000 independent paths and its own SeedSequence child under root seed 20260922. We use the paper's binary mid increments and pre-step quotes, with independent bid and ask Bernoulli trials. All paths use 200 steps. Terminal profit marks inventory at the final mid and subtracts initial marked wealth. No transaction fees, queue priority or latency are modelled.

Intervals are pointwise percentile 95% bootstrap intervals from 2,000 resamples of whole paths. Standard deviations use ddof=1. Ratio intervals independently resample the two strategy path sets. The acceptance comparison asks whether each paper point estimate lies inside the corresponding interval; it does not incorporate the original paper's unavailable Monte Carlo uncertainty. Simultaneous coverage of every metric is not 95%. Seeds, conventions and diagnostics were recorded before the full experiment. No failed assertion, target or tolerance was weakened.

## Primary outcome

The full equation 3.18 spread is primary. Literal Bernoulli probabilities must lie in [0,1]. At gamma 0.1 the inventory run stops at zero-based step 3 with raw probability 1.165030467455133. At gamma 0.5 it stops at step 1 with raw probability 1.313609693076878. These are invalid probabilities, not successful paths. At gamma 0.01 both strategies complete, but several reference targets fall outside the simulation intervals.

## Interpretation and self-audit

- **BLOCKER:** the current source and implementation do not establish numerical replication. Neither diagnostic variant meets all reference comparisons. M1 remains in progress.
- **SUSPECT:** the paper's table spreads omit the time-dependent risk term, while its formula and benchmark description include it. Source code or author clarification would be stronger evidence than choosing whichever interpretation fits best.
- **SUSPECT:** the paper does not specify probability overflow handling, bid/ask dependence, random seeds or the standard-deviation divisor. The implementation records its choices.
- **SUSPECT:** capping probabilities materially changes some cases. It is explicit, counted and disqualified from primary acceptance. It must not be described as faithful Poisson simulation.
- Accounting uses an independent economic increment identity checked at every step. Quotes and fill probabilities use only the current state. Reproducibility tests verify identical comparison JSON and Parquet bytes on repeated fixture runs.
- M0 was accepted by the user; the real one-hour collector acceptance evidence remains absent. It is not recast as passing. No holdout or fitted market data was used.

Timestamps and run IDs differ across reruns; scientific comparison content and path samples are deterministic for the pinned environment.
