## Findings on the fixture worth carrying forward

- **Time aggregation biases elasticity toward zero.** Depth at the start of a 1 s interval is a stale regressor: both elasticities come out about half as large as with 50 ms intervals. Use short intervals on real data.
- **Total-level cancel elasticity is not the per-order exponent.** Order counts scale sub-linearly with depth, so the fitted total-level elasticity sits about 0.35 below the generator's parameter. Comparative statics are correct. The simulator uses the total-level quantity, which is what the data identifies.
- **With e_cancel near 1, A3 has almost no channel.** Our extra depth changes others' cancel flow by ((D+v)/D)^(e-1). This is consistent with the PRD's expectation that A3 is the weakest axis.
- **Mechanical impact is adverse selection too.** With the informed component switched off, measured 1 s adverse moves stay positive (+13 vs +27 quanta). The execution depletes the touch. A2 therefore measures mechanical plus informational adverse selection. The writeup should say so.
