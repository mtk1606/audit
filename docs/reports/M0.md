## Reconstruction contract

Initial state and newly visible boundary levels are supplied by reference snapshots and labelled as such. Retained levels and observable event-driven changes are independently checked. Supplied cells are not independent validation evidence, and aggregate snapshots do not establish individual queue identity.

LOBSTER provides no exchange sequence field. `sequence_gaps` remains null and is not interpreted as zero. CROSS and HALT are distinct source events. The price unit remains USD 0.0001 to preserve hidden sub-cent executions exactly.

## Engineering checks

Linting, formatting, strict typing, and 48 tests pass. New tests cover half-even ties, exact signed deltas, Decimal context independence, unchanged integral timestamps, strict rejection, day boundaries, provenance in manifests, timestamp collisions, and source reversals hidden by rounding. The tests initially failed because the normalization interface was absent. No original assertion was weakened or removed.

Collector tests include sequence gaps, snapshot buffering, restart persistence, and a forced disconnect over local HTTP and WebSocket servers. These fixtures do not satisfy the live one-hour acceptance requirement. Remote CI is configured but was not run here.

## Review findings

No unresolved blocker remains in the approved timestamp change. Canonical ordering is preserved, source reversals remain errors, and no timestamp conversion uses binary floating point.

The remaining limitations are unchanged: bounded snapshots lack complete FIFO identity; reconnect snapshots cannot recover missing event history; a live collector run is still required. No model replication, calibration, policy fitting, holdout evaluation, or P&L calculation has been performed.

## Next step

Run the collector on user hardware and retain its manifest and capture. Review continuity, the disconnect outcome, and the M0 acceptance criteria before moving to M1. M1 also requires the human-owned golden table and derivation.
