**Status: substantial numerical agreement; primary acceptance remains incomplete.** The supplied published article resolves the previous source-version and spread-definition questions. ## Source corrections

The supplied PDF is *High-frequency trading in a limit order book*, Quantitative Finance 8(3), April 2008, 217-224, DOI 10.1080/14697680701381228. All values in the supplied JSON were visually checked against printed pages 222-223 and match. Both JSON versions remain unchanged; no human verification is claimed.

The published symmetric strategy uses the time-averaged spread, held constant around the mid. Its value is gamma*sigma^2*T/2 + 2*log1p(gamma/k)/gamma. The inventory strategy retains the time-dependent spread. Table 3 uses gamma=1 rather than the earlier working paper's gamma=0.5. All reference outcomes differ from the earlier working paper.

We use the continuous time average, which matches the rounded table spreads. The average across the simulation's left-endpoint grid differs by gamma*sigma^2*dt/2; this discretization convention is explicit rather than fitted from rounded table values.

## Experiment

Run from clean source commit `60542eb0005e5e1f7ec8cd971bacc7b554008b8c`. Root seed 20260922, independent child streams under namespace (2008,), 1,000 paths per strategy/case, 200 steps, 2,000 bootstrap resamples. Timing, binary price increments, independence between bid/ask draws, ddof=1 and acceptance thresholds are unchanged from the prior protocol. No seed search was performed.

Intervals are pointwise percentile 95% intervals with whole independent paths as the resampling unit. They do not include uncertainty in the paper's original Monte Carlo estimates. The variance ratio is symmetric profit variance divided by inventory-strategy profit variance; its point estimate must be within 10% of the source ratio.

## Interpretation

The published source explains much of the earlier disagreement. The numerical agreement in the saturated cases is consistent with the authors having used a uniform-threshold rule that effectively caps probabilities. It is not proof of their code or intended convention. Strict validity still fails for Tables 1 and 3, and the independent Table 2 diagnostic misses the point-ratio tolerance. No acceptance criterion was changed and no passing cases were pooled across variants.
